# PAJARERÍA


## Descripción Funcional

Este proyecto es una aplicación Java que gestiona las compras y ventas de una pajarería. Nos permite registrar especies de pájaros, realizar stock de los mismos, implementar facturas y recuperar facturas. Para estos dos ultimos puntos daremos de alta a los clientes, obteniendo así un registro del mismo. 

## Requisitos

Para compilar y ejecutar este proyecto, necesitas tener instalado:

* **Java Development Kit (JDK) 11 o superior.**
    * Puedes descargarlo desde [Oracle JDK](https://www.oracle.com/java/technologies/downloads/) o [OpenJDK](https://openjdk.java.net/install/).
* **Apache Maven 3.6.3 o superior** 
    * Maven: [https://maven.apache.org/download.cgi](https://maven.apache.org/download.cgi)
    

## Instrucciones de Compilación y Ejecución

Sigue estos pasos para poner en marcha el proyecto:

### Con Maven

1.  **Clonar el repositorio:**
    ```bash
    git clone [https://github.com/tu-usuario/EntornosDesarrolloProyecto1.git](https://github.com/tu-usuario/tu-proyecto-java.git)
    cd 
    ```
2.  **Compilar el proyecto:**
    ```bash
    mvn clean install
    ```
3.  **Ejecutar la aplicación:**
    ```bash
    java -jar target/Pajareria-1.0-SNAPSHOT.jar
    ```


## Instrucciones de Uso

Actualmente es una aplicación de consola, donde al ejecutarlo, encontrarás un menú muy intuitivo que te irá guiando por todas las opciones. Actualmente, no se encuentra desarrollada la interfaz gráfica. 

Una vez ejecutada la aplicación, se mostrará un menú en la consola con las siguientes opciones:
1.  Gestion de clientes
2.  Gestion de pájaros
3.  Realizar venta
4.  Mostrar venta
5.  Salir
Introduce el número de la opción deseada y sigue las instrucciones."
